This will help you get started with `AzureAIOpenAIApiChatModel` [chat models](/oss/langchain/models).

The `AzureAIOpenAIApiChatModel` class uses the OpenAI-compatible API available in Azure AI Foundry. AI Foundry has several chat models, including AzureOpenAI, Cohere, Llama, Phi-3/4, and DeepSeek-R1, among others. You can find information about their latest models and their costs, context windows, and supported input types in the [Azure docs](https://learn.microsoft.com/azure/ai-studio/how-to/model-catalog-overview).

Microsoft Foundry provides project-level access to models and Azure services. Use `AzureAIOpenAIApiChatModel` from `langchain-azure-ai` when your application uses a Foundry project, Azure credentials, or other Foundry capabilities.

## Setup

To access `AzureAIOpenAIApiChatModel` models, create an [Azure account](https://azure.microsoft.com/pricing/purchase-options/azure-account), deploy a model, and install the `langchain-azure-ai` integration package. Microsoft Entra ID authentication with `DefaultAzureCredential` is the recommended authentication method.

### Credentials

Follow the [Microsoft Foundry documentation](https://learn.microsoft.com/en-us/azure/ai-studio/how-to/develop/sdk-overview?tabs=sync&pivots=programming-language-python) to create a project and deploy a model. For local development with Microsoft Entra ID, run `az login`, then set your project endpoint:

<Tabs>
    <Tab title="Shell">
        ```bash
        export AZURE_AI_PROJECT_ENDPOINT="https://<resource>.services.ai.azure.com/api/projects/<project>"
        ```
    </Tab>
    <Tab title="Python">
        ```python
        import getpass
        import os

        if not os.getenv("AZURE_AI_PROJECT_ENDPOINT"):
            os.environ["AZURE_AI_PROJECT_ENDPOINT"] = getpass.getpass(
                "Enter your Azure AI project endpoint: "
            )
        ```
    </Tab>
</Tabs>

If you want to get automated tracing of your model calls, you can also set your [LangSmith](/langsmith/observability) API key:

```python
os.environ["LANGSMITH_TRACING"] = "true"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
```

## Instantiation

Use the Responses API with Microsoft Entra ID for new applications. The alternatives show how to use Chat Completions with either Microsoft Entra ID or an API key.

<Tabs>
    <Tab title="Responses API (recommended)">
        ```python
        from azure.identity import DefaultAzureCredential
        from langchain_azure_ai.chat_models import AzureAIOpenAIApiChatModel

        llm = AzureAIOpenAIApiChatModel(
            model="your-model-deployment",
            credential=DefaultAzureCredential(),
            use_responses_api=True,
            store=False,
        )
        ```
    </Tab>
    <Tab title="Chat Completions with Entra ID">
        ```python
        from azure.identity import DefaultAzureCredential
        from langchain_azure_ai.chat_models import AzureAIOpenAIApiChatModel

        llm = AzureAIOpenAIApiChatModel(
            model="your-model-deployment",
            credential=DefaultAzureCredential(),
            use_responses_api=False,
        )
        ```
    </Tab>
    <Tab title="Chat Completions with API key">
        ```python
        from langchain_azure_ai.chat_models import AzureAIOpenAIApiChatModel

        llm = AzureAIOpenAIApiChatModel(
            endpoint="https://<resource>.services.ai.azure.com/openai/v1",
            model="your-model-deployment",
            credential="your-api-key",
            use_responses_api=False,
        )
        ```
    </Tab>
</Tabs>

LangGraph agents keep conversation history in graph state, so use `store=False` to disable model-side response storage. For direct Responses API calls, pass prior messages to manage history in your application, or use `store=True` with `previous_response_id` to continue a conversation from model-side storage.

    ),
    ("human", "I love programming."),
